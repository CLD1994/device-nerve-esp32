# 单向低速试验

此分支只新增主机工具，不修改或烧录固件。需要支持 CALIB? 和供电门的固件；准备分支不代表已执行设备运动。

## 现场前提

确认本次位置已标定、坐标比例可信，小车处于中间；摆杆自然下垂，扫掠空间无人员与障碍。人工确认近期供电已验证为20V，有可立即使用的独立电机断电手段。固件没有电压查询协议，工具不宣称读取了实时电压。

关闭占用控制口的软件。在项目根目录运行，日志文件必须是新路径：

```powershell
python tools/low_speed_probe.py --port COM11 --baud 460800 --out low-speed-plan.jsonl plan
```

plan只查询QUERY、CALIB?、CONFIG?，不配置、不使能、不发送VEL。run不会自动ENABLE或RESET；需人工单独使能并确认READY后，才明确执行：

```powershell
python tools/low_speed_probe.py --port COM11 --baud 460800 --out low-speed-run.jsonl run --velocity 20 --acceleration 100 --hold 0.5 --confirm-motion
```

run将VEL_MAX设为20、ACC_MAX设为100、WDT_MS设为100、WDT_DEC设为100；每项回执须匹配，不恢复旧的高值。ACC_MAX用于正常速度变化及VEL0，WDT_DEC用于命令超时减速，两者不是同一参数。试验后电机仍可能使能。

## 轨迹与中止

仅正向运动，在目标速度±1mm/s容差内后保持0.5秒，然后请求零速并检查停稳。理想对称斜坡估算14mm，**不是最大位移保证**。参数限定正向1–20mm/s、加速度100mm/s²、保持时间0–0.5秒（不含0）。低于速度噪声的档位不适合测量加速度。

独立总非零命令窗口为v/a+hold+0.1秒，默认0.8秒；即使没检测到到速也会截止。设置距起点正向30mm、反向3mm及相邻帧跳变3mm的软件中止预算，逐帧检查并在停止阶段保留，并在两侧软边界内再保留50mm；这些均使用固件坐标，不替代独立尺量与实际制动余量。Python和操作系统非实时，串口写超时也不是硬件最大延迟保证。

工具持续有界读取，不在等待人工输入时打开串口积压。每次非零目标前要求收到更新的状态；异常行、FAULT、超时或位置越预算则退出运动。没有独立重发最后速度的喂狗线程。Ctrl-C与异常经过finally尽力VEL0并有限检查停稳。若不能确认，请立即独立断电；拔串口、退出程序、写入VEL0成功均不是物理停机保证。

协议没有设备时间戳和序号，最近收到的新行仍可能是缓冲旧数据；工具不能证明毫秒级真实采样新鲜度。停稳判定要求主机连续观察至少200ms、每批所有帧速度绝对值≤1mm/s且位置跨度≤100µm，不能代替现场观察。串口故障分析与物理测量仍需独立完成。

## 记录与验证

JSONL记录原始接收字节、发送命令、配置快照、中止及停稳结果。运动时内存有界记录，退出后写文件，突然断进程可能失去未落盘记录。文件时间为主机时间，不是设备采样时间。本试验只验证低速方向、响应与停稳，不给出机械最大加速度。

```sh
python -B -m unittest discover -s tools -p test_low_speed_probe.py -v
```

测试使用纯内存串口替身，不访问设备。真实固件、电源、制动与急停未由单元测试验证。

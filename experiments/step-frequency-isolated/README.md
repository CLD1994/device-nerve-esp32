# STEP 频率隔离诊断（ESP32-S3，rev2板）

**这是独立测试固件，不是小车运动命令。完成物理隔离及仪器确认前，不要烧录或运行。**
宿主测试通过不代表24/32/40/50kHz输出达标。

## 物理隔离前提

所有电源断开后，隔离电机功率供电路径，或在断电时断开电机连接。先核实板上
USB、VM和PD供电关系，只保留所需逻辑供电，禁止带电插拔电机线。
电源或之前的PD协商可能仍提供20V：**固件不请求20V，不等于VM没有20V**。
GPIO21高电平和软件状态都不能证明物理隔离；不能依赖复位期间GPIO状态作为安全屏障。
必须有随手可用的物理断电手段，不能通过使能小车并发送高速命令替代此实验。

仪器通道接GPIO5 STEP，地线接已核实的板级GND，第二通道观察GPIO21 EN
（高为禁用，低为使能）。GPIO6 DIR由引擎正向目标控制。仪器输入需兼容3.3V。
不要将接地示波器地夹接到VM或电机相线。开始前确认示波器/逻辑仪型号、实际采样率
及记录长度。实际记录长度、采样率和仪器设置须现场核实，标称带宽不能代替这些参数。

## 构建与生产固件隔离

测试直接链接**未经修改的生产step_engine.c和vel_ramp.c**，使用GPIO5/6及1MHz
GPTimer，不用简化ISR替换。入口不链接或初始化电机驱动、cartpower、cartfsm或Unity
电机测试，没有ENABLE/VEL/CURRENT命令，也不请求PD升压。EN输出前先预装高电平，
入口从不主动拉低EN。

本应用明确将app_main固定在CPU0；sdkconfig默认指定CPU0，源码还设编译检查和
GPTimer注册前的运行时核心检查。所有引擎API只由该任务调用，GPTimer中断在同核分配。
这是隔离测试的执行约束，**不是生产环境跨核停止竞态的修复或正确性证明**。
改变任务核心/调用结构需重新审查，不能删除检查后仍沿用停止结论。

在仓库根目录、ESP-IDF开发容器中构建：

```sh
source /opt/esp/idf/export.sh
probe_build="$PWD/build/step-frequency-isolated"
idf.py -C experiments/step-frequency-isolated/firmware -B "$probe_build" \
  -DIDF_TARGET=esp32s3 -DSDKCONFIG="$probe_build/sdkconfig" build
```

核实目标设备和物理隔离后，才能使用产物生成的flash_args。本说明不自动烧录。
工程名为`cartpole-step-isolated`，不能与正式cartpole固件混淆。构建目录及sdkconfig
不能复用生产目录。CPU/Flash/PSRAM/watchdog默认值继承根目录配置；中断及任务
watchdog保持开启。STEP_ENGINE_TEST_HOOKS默认关闭，测未经插桩的生产ISR。
任何修改后的构建配置均需记录；开启插桩会改变被测负载。

## 显式命令，禁止自动运行

UART0：GPIO43 TX、GPIO44 RX、460800 8N1，与构建选择的日志控制台分开。
启动输出`STEP_PROBE state=0 reason=BOOT_IDLE`后等待。一次发送一条换行结尾的ASCII命令：

| 命令 | 行为 |
| --- | --- |
| `INFO` | 请求元数据/状态；运行期间延迟到停止后报告。 |
| `STOP` | 停止STEP输出，保留已锁存的故障。 |
| `RUN 1000 500 ISOLATED` | 操作者明确确认物理隔离，执行一次1000STEP/s、总时长500ms的测试。 |

`ISOLATED`是操作者声明，**不是传感器证明**。频率只能选择1000、5000、10000、
16000、20000、22000、24000、28000、32000、40000、50000STEP/s；时长为200～1000ms整数。
其他命令、不匹配的命令行、UART帧/奇偶/溢出/break错误及非IDLE时RUN均锁存FAULT。
串口入口兼容CR字符（收集行时忽略CR），不能把这描述为拒绝一切非标准换行。
故障须复位后重新开始；复位只回到等待，不自动恢复目标。RUN令牌不构成持续授权。
**不要设置终端自动重复RUN**。正常到期或STOP后可通过新的显式RUN执行下一次。

每次测试包含约100ms加速过程（加速度为频率的10倍，单位STEP/s²），不是保证拥有
200～1000ms稳态平台。使用生产速度递推，不绕过它生成恒频波形。到期或STOP调用
生产立即停止STEP接口，不执行机械减速，因此只能用于电机物理隔离状态。

控制任务在有界串口处理前后监督时限；运行期间每20ms喂引擎命令看门狗，观察到
50ms及以上间隔即锁存故障，禁止恢复旧目标。引擎命令watchdog为100ms，任务不再
喂狗时引擎减速。EN读到低电平也停止并锁故障。活动控制循环不执行同步串口或控制台
报告，停止STEP后才输出。这些是软件保护，不是硬实时承诺：ISR饱和、调度、复位及
看门狗报警都应记录为失败，不能关闭watchdog来提高成绩。软件监督不替代物理隔离。

state=0/1/2分别为IDLE/RUNNING/FAULT。报告包含原因、EN回读、目标频率、总时长、
软件STEP计数、IDF及构建版本。总时长含斜坡及监督延迟；软件计数不是独立脉冲测量。

## 50kHz显式试验档

在物理隔离与仪器条件已确认、此前档位已检查的前提下，可显式发送
`RUN 50000 1000 ISOLATED`。该频率属于隔离诊断白名单，不更改生产固件或其他保护边界。
50kHz目标周期为20µs，在1MHz定时分辨率下可整除；相比32kHz向下量化为31µs，
这一档没有小数周期截断，但中断延迟及排程仍可能使实际波形偏离目标。
加速度沿用目标频率的10倍，即500000STEP/s²，约100ms爬升，1000ms总时长
包含爬升；不得把约900ms平台或约47500个理想脉冲当成实测保证。
50kHz是当前诊断最高允许档，不是ESP32或生产ISR的已验证极限。

捕获应包含起步、平台和停止后时段；平台核查20µs周期分布、约1µs高脉宽、
长间隔及外部边沿数。建议50～100MS/s并核对记录深度，不能只看一个20µs局部截图。
若出现故障、看门狗或无法按时停止，不得关闭保护再试。以下隔离与测量边界仍全部适用。

## 外部测量与停止条件

从1kHz开始，检查前档波形后才单独选择更高档。不自动扫频、重试或故障后继续。
每档排除起步斜坡，测量稳态：

- 外部上升沿数量、实际频率与周期分布；
- 最小/最大高低电平宽度、长间隔、多余或窄脉冲；
- 停止后是否还有脉冲、EN是否全程高电平；
- watchdog、复位、通信状况、构建配置与采集时长。

约1µs高电平只是代码意图，不是实测。建议50～100MS/s检查脉宽，初步检查至少
20MS/s，并确认选定通道数下的实际采样率。占空比不要求50%。长时间原始采集可能
耗尽仪器存储，应结合短窗口高分辨率采集及适当门控计数/分段采集，区分仪器漏采与
设备丢脉冲。只看软件计数无法证明引脚实际发出了所有边沿或达到目标频率。

本镜像测的是**隔离引擎基线**，不含生产编码器任务、500Hz遥测、FSM或正常通信负载。
不能把基础通过当成生产负载上限。带负载对比属于另一个阶段，不应通过伪造编码器
运动或绕过电机保护来冒充生产测试。结果只能说明特定构建、负载及观察窗口下的最高
通过档，不是绝对硬件上限，也不能直接等同小车机械速度。

## 离线验证边界

```sh
bash experiments/step-frequency-isolated/tests/run.sh
```

已运行的纯C测试只覆盖控制策略及解析：参数边界、控制对象初始状态、EN拒绝、显式
重新启动、故障锁存、20/50ms时序、到期停止及倒退时钟。**没有执行ESP-IDF串口适配层、
真实app_main启动或GPIO**；UART错误事件映射、运行期间不打印、停止后才输出目前是
代码静态检查，不应称为整机测试通过。

目标构建、现场物理隔离确认与外部波形测量分别验证不同层次。
仅通过宿主测试，不能称此固件已经过硬件验证。

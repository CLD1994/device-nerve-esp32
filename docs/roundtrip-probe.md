# 两次往返专用探针

`tools/roundtrip_probe.py` 仅手动启动一次左→右→左→右→左，目标速度1250 mm/s、ACC_MAX10000 mm/s²、WDT_MS100、WDT_DEC5000。普通VEL0使用ACC_MAX减速；预算仍按正常减速度5000的假设。脚本不设置电流，1.5A请求由当前实验固件及现场确认；不自动ENABLE、RESET、标定或清除FAULT。

名义端点为853.325mm标定行程减10mm软余量后的±416.6625mm。run要求有效标定参考、READY NONE、人工将小车放在左名义端点内侧5mm并保持静止（−416.6625 < x ≤ −411.6625mm）。不是贴住物理挡块。当前FAULT或参考未确认会拒绝，不自动恢复。

每段先向目标方向请求1250；按`1250²/(2×5000)+1250×0.05+50=268.75mm`正常条件余量，在±147.9125mm发零速。确认停稳且在最后非零请求的50ms在途假设后，再作为独立正常阶段100mm/s接近至距名义端25mm，停稳后20mm/s接近至距名义端4mm，再停稳。实际端点必须位于名义端内侧5mm，否则中止，不反复补偿。不保证精准抵达名义端点。

此轨迹不是全部以1250运行。接近及每次停稳增加时间；不能用全行程/1250声称约3秒完成。高速每段非零上界1s、每个低速接近上界20s；它们只用于中止，不用于判定抵达端点。每端停稳、MODE/速度有效性均符合才允许反向。

## 必须了解的边界

- 条件正常制动能力5000、在途50ms、额外50mm均非本脚本实测证明。1250时故障停止估计（含WDT100ms）需393.75mm，比正常余量大125mm，不能保证故障/晚到命令时在挡块前停车。运行要求明确接受该条件停距风险，现场人员必须能立即独立切断驱动电源；断电也不保证立即静止。
- 软边界只作为拒绝/中止检查，不能代替提前制动或硬限位；已跨越时才检查不能撤销运动。
- 任一FAULT、传感器失效、异常协议、续发50ms超时或位置越界均取消所有剩余段及低速接近；不自动重试。
- 持续零速请求不等于禁用电机；成功后不自动DISABLE。
- 保留JSONL中的四段起点、提前制动后位置、低速阶段、实际停点、全部原始接收及abort。速度/位置来自传感器报告，不能证明真实加速度、50kHz波形、无滑动或故障停车上界。

## 用户现场手动执行

先仅查询计划（不会配置或运动）：

```powershell
python tools/roundtrip_probe.py plan --port COM11 --baud 460800 --out roundtrip-plan.jsonl
```

现场处理已有FAULT、验证真实静止/位置参考及1.5A、按上述起点要求准备，并由用户自行确认使能及净空后，才手动运行：

```powershell
python tools/roundtrip_probe.py run --port COM11 --baud 460800 --out roundtrip-run.jsonl --confirm-motion --confirm-clearance --accept-stopping-risk
```

每次文件名须为新文件；已有文件拒绝覆盖。脚本不会替用户处理这些前置现场操作。

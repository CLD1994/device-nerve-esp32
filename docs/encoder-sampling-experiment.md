# 编码器 2 kHz 采样实验

## 范围与开关

`idf.py menuconfig` 的 `magnetic_encoder - 磁编码器类别` 下提供
`CONFIG_MAGNETIC_ENCODER_EXPERIMENT_2KHZ`。默认关闭，保留 1 kHz 的
FreeRTOS tick 调度；开启后目标间隔为 500 µs。两路编码器一起切换。
任务仍在 CPU1、优先级 3；SPI 时钟不变，STATE 遥测仍为 500 Hz。
目标频率不是实测能力声明。

2 kHz 使用 `esp_timer` 任务回调发通知，SPI 与解码仍由采样任务执行。
回调不做SPI。每个实际单调时间的500 µs周期最多读取一次；任务迟到时
读取当前样本，不重放历史周期。一次读取期间积压的通知丢弃，随后等待
新的通知；延迟回调在同一实际周期重复到达时不会重复采样。
周期编号去重不等于严格均匀500 µs，跨周期边界的两次读取仍可能靠近。
必须通过成功样本间隔统计观察抖动，不能从通知频率推断采样已达标。

速度窗口保持名义约16 ms：1 kHz为17点，2 kHz为33点，仍使用真实读帧
完成时间差。最大32 ms窗口与小车位置连续性预算保持不变。
连续10次失败的健康阈值仍按次数计算，2 kHz下对应时间比1 kHz更短。
任何单次读取失败依然立即使速度无效并重新预热。

## RAM统计与导出

`CONFIG_MAGNETIC_ENCODER_SAMPLING_STATS` 默认随2 kHz实验开启，也可
在1 kHz单独开启用于对照。采样任务只更新每实例RAM统计；另外的CPU1、
优先级1任务每5秒取快照并写日志。导出任务的调度、格式化和日志UART仍
有开销，不是零干扰；对照组应使用相同导出配置。初始同步读帧不计入统计。
统计是自采样任务开始以来的累计值，未提供运行期复位。
这些指标不是CPU总负载。本实验未启用FreeRTOS运行时间统计，不能声称
测得CPU利用率。导出任务不持有采样锁做日志，低优先级降低直接抢占影响，
但不能保证系统资源争用为零；日志干扰若触发5 ms连续性保护，也按真实
失效处理，不因“只是打印”而放宽保护。新配置的默认值只在实验开关开启时启用导出。

字段含义：

- `elapsed_us`：首个任务读帧开始至导出时的时间。尝试次数减失败次数，
  除以此时间，可作累计成功采样率近似；它不是严格首末成功样本帧率。
- `attempts`、`fail`：任务读帧次数和失败次数。
- `success_dt_us`：连续成功读帧完成时刻之间的最小/最大间隔，含失败空窗。
- `read_max_us`：`read_frame`调用耗时，含驱动等待、传输和解码，不只是线上SPI位时间。
- `work_max_us`：一次读取至发布、状态处理和看门狗更新结束的耗时，不含统计导出任务。
- `latest_notify_to_start_max_us`：最新已观察回调通知到任务起读的延迟。
  合并通知时它不是最老通知等待时间，不能当作任务调度延迟的严格上界。
  1 kHz旧调度路径不使用通知，值为0而不是证明零调度延迟。
- `read_overrun`、`work_overrun`：上述耗时严格超过目标周期的次数。
- `skipped`：两次实际起读周期编号之间未执行读取的周期数，只对2 kHz路径有意义。
- `discarded`：已送达但合并、同周期拒绝、或在工作期间丢弃的通知数。
  `esp_timer`内部跳过的回调不计在此数中；它与`skipped`不是同一指标。

## 联合验证

先保持电机禁用，不以提高采样率为由提高运动参数。

1. 记录固件提交、开关、SPI频率和两路传感器型号；分别构建1 kHz与2 kHz。
2. 两组均开启统计，静止运行至少60秒，再缓慢手动移动，保存完整日志。
3. 比较两路累计成功率、最大成功间隔、读帧耗时、超期与错误。若位置连续性
   失效，已有保护会停STATE；即使后续速度恢复也须重新定位，不能绕过保护。
4. 确认500 Hz STATE、QUERY应答与`VEL_VALID`行为未退化。
5. 后续运动测试需另行确认条件。这里的host测试只证明代码与边界行为，
   不证明ESP32调度、SPI吞吐、实际2 kHz、STEP上限或最大加速度。

回退时关闭2 kHz开关重新构建烧录；不需要修改NVS标定记录。
`menuconfig`中已经保存的`CONFIG_MAGNETIC_ENCODER_SAMPLING_STATS=y`
不会保证随2 kHz开关关闭而自动撤销。回退及两组对照前都应显式检查
采样开关与统计开关，按实验计划设置统计配置一致，不能只依赖默认值。

## 已有真机观察与合并边界

2026-11-13，操作者在 ESP32-S3、ESP-IDF v6.1 上对实验固件完成了
1 kHz 与 2 kHz 的静止对照。两组均开启采样统计，遥测目标为500 Hz。

| 路径 | 小车编码器成功间隔范围 | 摆杆编码器成功间隔范围 | 观察结果 |
| --- | --- | --- | --- |
| 1 kHz，约35秒 | 127～1478 µs | 471～1431 µs | 两路 fail=0，read/work overrun=0。 |
| 2 kHz，约45秒 | 283～906 µs | 360～767 µs | 两路 fail=0，read/work overrun=0；小车 skipped=1、discarded=1，摆杆均为0。 |

这是具体试验窗口内的观察，不是所有负载下的保证。后续另一轮2 kHz启动
约5秒的小车统计出现 skipped=34、discarded=34；因此本功能保持可选且默认
关闭，不声明严格每500 µs都有新样本，也不声明全负载无跳采。统计累计值
需要结合运行时长、固件版本和任务负载解释。

本改动依赖真实采样时间、速度有效性和位置连续性保护。拆分后的分支需
另外完成 ESP-IDF 目标构建；宿主测试不能替代目标编译或上述真机观察。

# 新装置部署串口协议（Hi3516CV610 ↔ ESP32-S3）

板对板 UART 直连（3.3 V TTL，共地），**460800 8N1**，ASCII 行文本。链路上分两个面，共用一条物理串口，按行首单词分发：

- **数据面**：ESP32-S3 → CV610 的 500 Hz 状态流（`STATE` 行），只携带物理量遥测，不携带任何控制语义或状态标志。
- **控制面**：双向的命令与应答。CV610 以命令驱动 ESP32-S3：运动命令（`VEL`）、标定与流程命令（`MARK LEFT`/`MARK RIGHT`/`ENABLE`/`DISABLE`/`RESET`）、状态查询（`QUERY`）、运行参数配置（`CONFIG`）。固件以模式事件（`MODE` 行）与配置/标定应答（`OK`/`ERR` 行）回应。

消息名与枚举值用完整英文单词，不用缩写——在 460800 下保留便于调试的可读格式，但必须计入带宽预算；字段保持固定顺序的十进制整数，不采用 key=value（每种行只有一个固定格式，键名重复约 40% 字节却不消除任何歧义）。所有行首单词与枚举词**大小写敏感，全大写**。

带宽核算（含换行，8N1每字节10位）：四个int32字段的保守最长文本为54字节，
500 Hz时为27 kB/s，占460800发送容量46.08 kB/s的58.6%。
`STATE -249 3141592 0 0\n` 为23字节，占约25.0%。
控制命令使用反向通道，不与STATE简单相加；MODE/OK/ERR应答共用固件发送通道。
这些是线路预算，不是已测稳定性或延迟保证。验证方法见[状态流验证指南](telemetry.md)。

多圈累计、单位换算和符号约定在固件侧完成，坐标原点由手动两点标定（`MARK LEFT`/`MARK RIGHT`）建立，线路上传输的已是物理量，端侧程序不做标定换算。

## 数据面：状态流（500 Hz，周期 2 ms）

```
STATE <x_um> <theta_urad> <vx_mm_s> <vth_mrad_s>\n
```

| 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `x_um` | int32 | µm | 小车位置。原点 = 两标中点，由手动两点标定建立；+x 方向见符号约定。 |
| `theta_urad` | int32 | µrad | 摆杆角度。直立 = 0，摆顶向 +x 倾斜为正，按 ±π 环绕输出（不用 21-bit 原始码）。 |
| `vx_mm_s` | int32 | mm/s | 小车速度，基于位置采样的真实时间差估计；采样目标为 1 kHz。 |
| `vth_mrad_s` | int32 | mrad/s | 摆角速度，同样由固件估计。 |

速度估计是行为要求，算法不限：静止时速度噪声 σ ≤ 5 mm/s（小车）、σ ≤ 10 mrad/s（摆杆），等效群延迟 ≤ 10 ms。

状态流在所有固件模式下持续发送。**数据面不携带有效性标志；字段有效性由控制面模式推断**——`theta_urad` 来自绝对编码器，任何模式有效；`x_um` 自标定完成（`CAL_DONE`）起有物理意义，此前为上电起累计值。

## 控制面：模式机、命令与应答

### 固件模式机

| 模式 | 电机 | 进入方式 |
|---|---|---|
| `DISABLED` | 关闭使能 | 上电默认；正常停稳后DISABLE，或FAULT经RESET回到此态 |
| `READY` | 使能，静止或跟踪 `VEL` | DISABLED 且两点标定完成后收到 `ENABLE` |
| `FAULT` | 常规故障斜坡停机；POWER立即停止STEP并禁用 | 故障，见转换表 |

模式转换（完整分类）。坐标由手动两点标定建立，标定语义见 `calib-spec.md`：

| 当前态 | 事件 | 次态 |
|---|---|---|
| DISABLED | `MARK LEFT` / `MARK RIGHT`（见标定决策表） | DISABLED |
| DISABLED | `ENABLE`（标定完成 `CAL_DONE`） | READY |
| READY | 丢步 / AS5600 或 MT6835 读取失败 / 供电失效 | FAULT |
| READY | `DISABLE`且引擎精确零速 | DISABLED |
| FAULT | 收到 `RESET` | DISABLED |

### `MODE` 行：模式事件与查询应答

固件在**每次模式转换时**推送一行，`QUERY` 查询时也回答同一格式：

```
MODE <mode> <reason>\n
```

| reason | 含义 |
|---|---|
| `NONE` | 无（非 FAULT 转换） |
| `STEP_LOSS` | 丢步（AS5600 位置与指令位置偏差超阈值） |
| `AS5600` | 小车编码器读取失败（历史器件名：rev2 起小车位实为板载 MT6835，字面量为线协议冻结值） |
| `MT6835` | 摆角编码器读取失败 |
| `POWER` | 供电验证失效或供电样本过期，立即停止STEP并禁用 |

`MODE` 行无 ACK，端侧晚开串口会错过开机以来的转换，因此端侧在启动同步和任何需要复核的时刻发 `QUERY` 补一拍。

### 命令

```
VEL <v_mm_s>\n            目标速度 [mm/s]，钳位 ±VEL_MAX 后斜坡跟踪
MARK LEFT\n               记当前实测位置为左端，回 OK MARK_LEFT <E µm>
MARK RIGHT\n              记右端并完成标定，回 OK MARK_RIGHT <L µm>
CONFIRM LEFT\n           用已保存行程确认当前位置为左参考点；不使能
CALIB?\n                 查询保存与本次定位状态（见标定保存指南）
ENABLE\n                  标定完成且20V供电验证有效后使能进 READY，推 MODE READY NONE
DISABLE\n                 READY且引擎零速时禁用；运动中ERR BUSY；FAULT不清除
RESET\n                   清除 FAULT
QUERY\n                   查询当前模式，回答一行 MODE
CONFIG <NAME> <value>\n   设置运行参数，回答 OK 或 ERR
CONFIG?\n                 dump 全部参数（调试与日志记录用）
```

标定与回执原则：`MARK LEFT`/`MARK RIGHT`/`ENABLE` 仅 DISABLED 态接受；拒绝时回 `ERR MARK_LEFT`/`ERR MARK_RIGHT`/`ERR ENABLE`；ENABLE的供电条件不满足时优先回`ERR POWER`（回执名是单 token），普通参数/模式拒绝时状态保持；存储与参考失败的语义见[标定保存指南](calibration.md)。`VEL`/`RESET` 在不适用态静默忽略、无回执。标定决策表（`L = E_right − E_left` 合法窗 100000–1000000 µm，域反向得负即拒）与 ENABLE 动作次序见 `calib-spec.md`。

命令 × 模式矩阵（完整分类）：

| 命令 | DISABLED | READY | FAULT |
|---|---|---|---|
| `VEL` | 忽略 | 执行 | 忽略 |
| `MARK LEFT` / `MARK RIGHT` | 执行或 `ERR`（标定决策表） | `ERR` | `ERR` |
| `ENABLE` | 供电验证有效且标定完成才执行，否则 `ERR POWER` / `ERR ENABLE` | 忽略 | 忽略 |
| `DISABLE` | 幂等回MODE DISABLED NONE | 精确零速才禁用，否则ERR BUSY | 回当前MODE与原因，不改变故障 |
| `RESET` | 忽略 | 忽略 | → DISABLED |
| `QUERY` | 回 `MODE` | 回 `MODE` | 回 `MODE` |
| `CONFIRM LEFT` | 执行或 `ERR`（见标定保存指南） | `ERR` | `ERR` |
| `CALIB?` | 接受 | 接受 | 接受 |
| `CONFIG` | 接受 | 仅非摆角/非X_INV参数 | 拒绝（`ERR`） |
| `CONFIG?` | 接受 | 接受 | 接受 |

`VEL` 语义：固件以不超过 `ACC_MAX` 的加速度向目标速度过渡，换向经零速；收到新 `VEL` 即更新目标并保持到下一条。非法行静默丢弃，目标不变。

命令看门狗：超过 `WDT_MS` 未收到有效 `VEL` 命令（链路断、端侧程序死）时，以 `WDT_DEC` 减速到 0，**保持 READY**——看门狗是瞬态保护，不改变模式机，命令恢复即继续跟踪。

软限位窗口 `X_MARGIN_UM`：标定行程 `L` 确定后，有效运动窗口为 `[−L/2+m, +L/2−m]`（`m = X_MARGIN_UM`）。`x` 越出窗口后，`VEL` 中向外的分量被替换为 0，向内不受限；运行中收紧 `X_MARGIN_UM` 立即生效。

### 参数注册表（`CONFIG` 命令可配置项）

| NAME | 默认值 | 合法范围 | 单位 | 含义 |
|---|---|---|---|---|
| `VEL_MAX` | 1000 | 1 – 2000 | mm/s | `VEL` 命令硬钳位 |
| `ACC_MAX` | 5000 | 100 – 30000 | mm/s² | 斜坡加速度上限 |
| `WDT_MS` | 100 | 10 – 1000 | ms | 命令看门狗超时 |
| `WDT_DEC` | 5000 | 100 – 30000 | mm/s² | 看门狗减速用减速度 |
| `X_MARGIN_UM` | 10000 | 1000 – 50000 | µm | 软限位两端余量（窗口 `[−L/2+m, +L/2−m]`） |
| `POLE_ZERO_URAD` | 0 | −3141592 – 3141592 | µrad | 摆角零位偏置：输出 θ = 原始读数 − 本值，使机械直立对应 0。标定法：θ₀ 取直立原始读数（可由下垂读数 + 180° 反推，比手扶更准），本值 = θ₀ |
| `POLE_INV` | 0 | 0 – 1 | — | 摆角符号翻转，使摆顶向 +x 倾斜为正 |
| `X_INV` | 0 | 0 – 1 | — | 小车 +x 方向翻转，使命令与 `x_um`/`vx_mm_s` 满足符号约定 |
| `STEP_LOSS_UM` | 3000 | 500 – 20000 | µm | 丢步判定阈值：指令位置与 AS5600 实测偏差超过即 FAULT |

`CONFIG` 语义：成功时回 `OK <NAME> <value>`（回显归一化后的值），参数立即生效；未知 NAME、超出范围、或当前模式为 FAULT 时回 `ERR <NAME>`。`POLE_ZERO_URAD` 和 `POLE_INV` 仅在 DISABLED 接受，NVS提交成功后才应用和回OK，失败回 `ERR CAL_STORAGE`；重启恢复。`X_INV` 也仅在DISABLED修改。其他参数使用默认值或由端侧会话配置。完整持久化、重启参考门和故障语义见[标定保存指南](calibration.md)。运行中收紧限制（调低 `X_MARGIN_UM`/`ACC_MAX` 等）立即约束当前运动；放宽不产生任何主动运动。

## 符号约定（实机验证方法）

摆角零位使用编码器的单圈绝对角，不以固件启动姿态归零。固件保存的
`POLE_ZERO_URAD` 和 `POLE_INV` 在机械安装和方向不变时可以跨重启复用，
NVS恢复规则见[标定保存指南](calibration.md)。
`RESET` 只清故障，不重置编码器累计状态或运行参数。
若零偏来自旧固件的开机相对角，升级后须重新标定，不能直接沿用该数值。
绝对角读取与累计位置的区别见
[编码器类别契约](superpowers/specs/2026-10-14-device-category-abstraction.md#magnetic_encoder绝对式磁编码器)。

- +x = 发 `VEL 200` 时小车实际移动的方向；同方向用手把摆顶掰过去时 `theta_urad` 必须增大。任一不符，先改固件符号再联调。
- `x_um` 沿 +x 增大；两个速度量与各自位置量同号。

## 时序

- 状态流目标为500 Hz（2 ms）。采样为1 kHz；速度窗使用17个成功样本，均为名义约16 ms，分母为实际采样时间差且总跨度不得超过32 ms。增加报告率不会缩短这个估计窗口。
- STATE的每路位置/角度与速度来自同一快照，两路之间不保证同步，也不携带时间戳、序号或校验和。不得仅由报告率推断新样本率或端到端延迟。
- 默认FreeRTOS tick为1000 Hz。构建要求tick能精确表示1 ms和报告周期，误配置时编译失败，不采用截断后的错误周期。
- 状态报告与控制频率解耦：本次不提高控制命令频率，也不启用1 kHz报告；端侧继续消费最新完整帧。
- 端到端延迟预算：策略输出 → 串口 → 固件斜坡响应 ≈ 1–2 个控制周期 + τ，喂给仿真动作延迟随机化（见 `sim2real-spec.md`）。

## 操作流程（演示当天）

1. 上电（DISABLED，状态流已在发送，摆杆自然下垂最安全）。
2. 端侧开串口，发 `QUERY` 同步当前模式，不依赖可能错过的事件。
3. 可选：`CONFIG` 推送本台位参数。
4. 手推小车到最左端 → `MARK LEFT`；推到最右端 → `MARK RIGHT`（回显 `L`，核对本装置实际可移动行程）。
5. 发 `ENABLE`，等 `MODE READY NONE`。
6. 端侧以小速度 `VEL` 把小车从右端移到 0 附近。
7. 人手把摆杆扶到直立附近，策略接管。
8. FAULT 后：`RESET`，查询 `CALIB?`；位置连续性失效时先手推左参考并 `CONFIRM LEFT`，再 `ENABLE`。断电后有可用保存行程时也走左参考确认；无可用记录则回第 4 步两点标定。

## 未决事项

- 500 Hz下验证当前波特率的长期接收与应答质量。不得直接降至230400/115200：54字节×500 Hz已超过这两档的线路容量；需要回退时使用先前验证的固件/频率组合。
- 速度估计器实测噪声与群延迟是否满足指标。
- 标定重复性实测（同一端点重复标记读数散布）。
- `L` 合法窗 100–1000 mm 是否按台位实测行程（≈530 mm）收紧。
- `X_MARGIN_UM` 默认值与合法范围依据实测微调。
- 参数注册表默认值与范围依据实测微调。
- MT6835 的 SPI 寄存器映射在固件实现阶段确定。
- 与旧协议（`deploy/protocol.md`）的关系：旧协议随旧装置退役，本文件为新装置唯一协议权威。

## 20 V 供电状态与运动门禁

ENABLE还要求供电验证有效；否则返回`ERR POWER`，不使能。供电验证条件与时序见
[硬件说明](hardware.md#14-正式固件的供电门禁)。标定、QUERY和CONFIG读取不要求供电就绪。
运行中供电失败/样本超时触发`MODE FAULT POWER`，立即停止STEP并禁用驱动，不承诺缺电
时的斜坡制动。`POWER`是新增reason值。RESET可将模式回DISABLED，但不会清除电源故障
锁定；输入恢复也不自动使能，须排查后重启验证。原有标定使能前提不变。

## 正常停止后的禁用

`DISABLE` 不自动减速，不是急停。先发送 `VEL 0`，观察小车停稳，再执行主机工具的 `disable`。READY下只有步进引擎精确速度为零才清目标、停止发步并关闭EN，随后回`MODE DISABLED NONE`；速度非零时回`ERR BUSY`且不改变目标或模式。DISABLED下重复执行幂等；FAULT下仅回当前故障，不清故障或中断已有停机流程。

速度判断与清目标在引擎锁内原子执行，输出锁防止并发VEL穿过禁用流程；后到VEL在DISABLED下忽略。禁用保留有效位置参考和保存参数，也不清供电失败锁；再次ENABLE仍需供电和参考门禁。

引擎速度为零不证明机械静止。关闭EN会失去保持力，不得把本命令作为对滑行、外力或坠落的安全保证。不可手推制造丢步故障来代替禁用。

## 测量有效性

遥测在有效性变化及周期心跳时发送：

```text
VEL_VALID <cart> <pole>
```

两项只接受 `0` 或 `1`，依次表示小车和摆杆测量是否通过当前算法的有效性检查。
两路都要求速度估计已有完整的实际时间窗口、最近一次读帧成功且未超过采样时效；
小车还要求累计位置连续性未失效。因此，小车字段为 `0` 也可能表示位置连续性已经失效、
尚未重新定位，即使速度窗口已经恢复也不会自动变回 `1`。应按既有标定/左参考确认流程
恢复位置参考，不得仅等待速度恢复就重新启动。`1` 只表示算法检查通过，不证明磁场健康、
实际位置正确、传动比例正确或运动安全。速度窗为17点，名义约16 ms，实际总跨度必须不超过32 ms；
32ms是有效性保护门限，不代表已证明的最佳滤波窗口或端到端延迟。跨度超过门限时速度无效，
保留滚动窗口，旧慢样本自然淘汰、整窗重新满足门限后才恢复；这不改变位置累计与原点。它不是磁场强度、传动比例、位置原点或实际运动安全的证明。
位置/角度与对应速度从同一路编码器的同一快照转换；两路编码器之间不保证同步采样。
任一路无效时不发送 `STATE`，不能用零速度或上一次有效速度代替无效测量。
两路有效时恢复原有四字段 `STATE` 格式。

`VEL_VALID` 在变化时立即报告，并在所有状态下每 100 ms 报告一次，允许新打开的串口会话
获知有效性。恢复报告排在随后 `STATE` 之前；同一次组帧通过一次互斥串口发送提交，
不会由另一个遥测线程交错发送旧 `STATE`。已进入串口缓冲的历史字节不能撤回，主机接收时间
不等于采样时间；此协议仍没有设备样本序号或时间戳，不能据此证明毫秒级端到端新鲜度。

运动工具必须先收到明确的 `VEL_VALID 1 1`，不能将未知状态视为有效。收到任一 `0` 时应清除
缓存状态，并在当前运动会话中锁存失败、停止续发非零目标、有限尝试零速停机。后续恢复为
`1 1` 不能自动恢复同一次试验。主机还必须保留接收超时、命令续发截止和行程检查。实验工具要求最近300ms内收到
有效性心跳，另保留100ms STATE接收年龄上限；这两个接收门限不是设备采样延迟上界。
旧工具可能把新行记为 `UNKNOWN`，不属于无条件兼容；应与固件同步更新工具。
普通诊断仍可查询旧固件，但缺少有效性证明时不得启动新运动试验。
`cartpole_host.py state` 的帧率只统计可解析的STATE行，兼容诊断可能包括有效性未知或
无效期间收到的行；帧率达到目标、UNKNOWN为0均不等于速度有效性验收通过。

速度窗口预热不产生新的 FSM 故障原因；主机运动工具在测量不可用时拒绝非零速度请求。
`DISABLE` 要求命令速度精确为零；位置连续性与电源保护由 FSM 独立检查。
实际更高速度的 STEP 能力须使用独立隔离固件测量，不能由估计器或宿主测试通过推断。

运动工具的同步日志写入和系统调度可能延迟协议处理；有效性检查不提供实时停机保证。

小车累计位置的连续性阈值由每转行程和应用传入的最高允许速度计算，最多允许
四分之一圈的位移预算。超过时间预算或时钟不递增时保留累计基准，以当前原始角度
重新播种，且锁存参考失效。速度窗口恢复不能恢复丢失的圈数；必须在 DISABLED 下
按[标定保存指南](calibration.md)重新确认参考。此工程预算不保证外力超速时仍能正确解缠。

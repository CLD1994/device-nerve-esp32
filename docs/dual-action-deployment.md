# 双动作固件分支

该分支增加[VELA 版本1](protocol.md#双动作扩展vela-版本-1)，用于速度与动态加速度限额模型。原单动作 VEL 仍可使用。协议权威同步入口为主仓库 deploy/v2/protocol.md。

新模型预期：400 Hz 控制，速度范围 ±1.25 m/s，加速度请求 0.1–9 m/s²，固件 ACC_MAX 配置为9000 mm/s²。这不是已烧录配置，构建和刷写不会替用户执行现场参数修改。WDT_DEC 必须保留独立配置，不能由第二动作改写。

发布前完成了主机替身头文件下生产 C 源语法核验、既有解析器回归及临时边界断言；没有新增测试套件。需要在 ESP-IDF 环境实际构建，并在人工监护下验证时序与停止行为，不能把云端检查当作真机验收。新分支未启动设备。

# 20 V 供电就绪与运动门禁

## 目标与边界
正式固件每次启动请求 CH224Q 的 20 V 档，核对 PD 状态及校准后的 VBUS，只有供电与行程标定均有效才允许 ENABLE。供电出错后禁止再次使能，需排除原因并重启。不会自动运动、自动使能或循环重新请求电压。

20 V 是否适合整板由硬件验收决定。本功能不能证明输入电容、保护器件、布线耐压，也不是硬实时过压保护。TMC2209 的芯片温度/短路保护保持原状；本改动不增加温度/短路遥测或固件安全保证。软件禁用后小车可能自由滑行，不能保证制动距离。

## 方案
沿用 CH224Q 驱动，增加独立 cartpower 组件：纯状态机负责时序和有效性，低优先级任务负责 I2C/ADC，FSM 只读取锁内缓存，不阻塞 1 kHz 运动监督。只修改启动日志而不约束 ENABLE 不能满足要求；把 I2C 放进运动监督会引入阻塞，故不采用。

## 状态契约
| 状态/输入 | 输出与后续 |
|---|---|
| 上电、未初始化 | EN 禁用，供电未就绪 |
| 初始化或请求20V失败 | 锁定 FAILED，不允许 ENABLE |
| 请求成功、等待稳定 | EN 禁用；从请求开始计时，至少等待3秒；PD未握手或电压未到目标允许等待，但 ADC 无效/读取失败/超过21.5V立即 FAILED |
| 连续5个间隔100ms样本 PD=1 且19–21V | VERIFIED；允许标定完成后的显式ENABLE |
| 请求开始满10秒仍未确认 | FAILED；超时优先于临界时刻的成功 |
| VERIFIED后PD丢失、电压不在19–21V、ADC/I2C失败 | FAILED锁定；运行中立即清STEP目标、停止引擎并禁用驱动，MODE FAULT POWER |
| VERIFIED最新样本超过500ms | FAILED锁定；拒绝ENABLE，运行中的同一停机路径 |
| RESET或输入恢复 | 不清除供电FAILED，不自动使能；重启才能重新请求 |

等待时间、请求超时、采样间隔、连续样本数、样本新鲜期限由cartpower配置提供合理默认值，不将历史一次3.4秒测量当作设备时限保证。20V目标及19–21V验证窗固定，不开放28V。

## 并发与时序
供电任务只发布缓存；FSM定时拍和ENABLE入口检查供电。有效样本时间戳取I2C读取开始而非结束，避免慢读取被伪装为新样本。默认采样100ms、I2C每次超时50ms；通常故障在下一次样本后被1kHz监督发现。任务调度延迟不保证硬实时上界；500ms新鲜门可在供电任务卡住时使FSM拒绝运动，但FSM自身卡住仍依赖现有看门狗及硬件保护。

POWER故障采用立即停止与驱动禁用，不依赖供电不足时的斜坡制动。故障态监督持续重申stop/disable，阻止已在途VEL更新留下输出。ENABLE在驱动开启前和开启后再次核对供电，已知失败绝不发布READY。

## 可观察性与验收
启动与状态变化记录目标、VBUS、PD及失败原因；拒绝ENABLE返回ERR POWER，运动故障返回MODE FAULT POWER。标定、串口查询继续工作。主机MODE解析须接受POWER。

真机检查在不使能电机时确认后级耐压、PD源能力、VBUS及3.3V；测试5V电源、PD断线、ADC不可用、重新上电均不自动使能。随后才做人工授权的低电流低速检查。宿主测试不能替代这些验收。

# 正常禁用命令

## 契约
`DISABLE`不自动减速，不移动，不清除故障或供电锁定，不擦除标定。

|当前模式|条件|结果|
|---|---|---|
|DISABLED|任意|幂等返回MODE DISABLED NONE|
|READY|引擎精确速度非零|ERR BUSY，状态/输出保持|
|READY|引擎精确速度零|同引擎锁清目标与停止，再关EN，发布DISABLED NONE|
|FAULT|任意|返回当前MODE FAULT及原原因，不改变故障处理|

输出互斥覆盖检查到关EN，所有在途VEL重新检查模式。引擎零速度不保证机械静止；操作者须先以VEL 0减速并观察，禁用后可能失去保持力。正常禁用不替代急停。恢复使能仍检查供电与有效参考。

## 实施与验证
1. 解析/主机/FSM先失败单元测试；引擎层独立原子检查停机接口及精确非零边界。
2. 接通motor/cartaxis/FSM与主机disable命令，移除手推制造故障建议。
3. 中文协议/标定指南；宿主全套回归与独立审查，目标构建和硬件验收明确单列。

尚无ESP-IDF目标构建、双核或真机运动验证。自然停稳路径中，递推同锁发布零速/停止标记，此后回调不再发步；正常禁用依赖此路径与FSM输出互斥。现有泛化急停与在途ISR同步是独立待核实问题，不属于此次修复结论。
